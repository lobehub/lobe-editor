## Introduction

Image plugin enables advanced image handling in the editor. It supports image insertion, resizing, caption editing, and provides a sophisticated image node system with serialization capabilities. The plugin includes internationalization support, custom styling options, and React components for seamless image integration with drag-and-drop functionality.

## Core Architecture

### Image Node System

The plugin implements custom image nodes:

- **BaseImageNode**: Foundation image node with core functionality
- **ImageNode**: Enhanced image node with advanced features
- **Caption Support**: Plain-text caption, editable inline under block images
- **Serialization**: JSON serialization for persistence and transport

### Command System

- **INSERT_IMAGE_COMMAND**: Insert images with various configuration options
- **Resize Commands**: Handle image resizing and dimension management
- **Caption Commands**: Manage image captions and visibility

### Internationalization

- **i18n Support**: Built-in internationalization for image-related text
- **Localized Labels**: Translatable image commands and interface elements
- **Multiple Languages**: Support for various locales and languages

### Image Features

- **Drag & Drop**: Native drag-and-drop image insertion
- **Resizing**: Interactive image resizing with aspect ratio preservation
- **Captions**: Plain-text captions, edited inline under block images
- **Placeholders**: `thumbhash` or `accent` color shown while the image loads, then a fade-in
- **Lightbox**: Clicking an image in read-only mode (`editable={false}` or `LexicalRenderer`) opens a zoomable preview
- **Loading States**: Support for image loading and error states

### Caption

`caption` is a serialized plain string on both `image` and `block-image`. Block images show an inline caption field under the image when it is selected (or already has a caption); press Enter or blur to save, Escape to discard. Read-only views render it as a caption below the image; inline images use it as the `title`.

Older documents that stored a nested caption editor state (`caption: { editorState }`) are migrated to the plain text of that state on load.

### Placeholder

`thumbhash` (base64 [ThumbHash](https://evanw.github.io/thumbhash/)) and `accent` (a CSS color) are optional. While the image loads, the decoded thumbhash is shown (or the accent color when there is no thumbhash), then the image fades in.

### Serialization

```typescript
interface SerializedImageNode {
  src: string;
  altText: string;
  width?: number;
  height?: number;
  maxWidth: number;
  status?: 'uploaded' | 'loading' | 'error';
  caption?: string;
  thumbhash?: string;
  accent?: string;
}
```

Empty `caption`, `thumbhash` and `accent` are omitted from JSON and LiteXML.

```xml
<img block="true" src="https://cdn/a.png" alt="A" caption="Valley at dawn" thumbhash="1QcSHQRnh493V4dIh4eXh1h4kJUI" accent="#3f6b4f"></img>
```

In Markdown the caption is the image title: `![alt](src "caption")`.

## Components

React component wrapper for image functionality.

## Commands

### INSERT_IMAGE_COMMAND

Upload a file and insert it as an image:

```typescript
editor.dispatchCommand(INSERT_IMAGE_COMMAND, {
  block: true,
  file,
  maxWidth: 800,
});
```

**Parameters:**

- `file`: Image file to upload (required)
- `block`: Insert a block image (defaults to `defaultBlockImage`)
- `maxWidth`: Maximum width constraint
- `range`: DOM range to insert at

To insert an existing URL with a caption, create the node directly:

```typescript
editor.getLexicalEditor()?.update(() => {
  $insertNodes([
    $createBlockImageNode({
      altText: 'Valley',
      caption: 'Valley at dawn',
      src: 'https://cdn/valley.jpg',
      thumbhash: '1QcSHQRnh493V4dIh4eXh1h4kJUI',
    }),
  ]);
});
```

## Plugin Configuration

### ImagePluginOptions

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| defaultBlockImage | Insert / parse images as block images | `boolean` | `true` |
| handleUpload | Upload handler | `(file: File) => Promise<{ url }>` | - |
| getImageWidth | Resolve the initial width of an uploaded file | `(file: File) => Promise<number>` | - |
| needRehost | Whether an image URL should be re-hosted | `(url: string) => boolean` | - |
| handleRehost | Re-host an image URL | `(url: string) => Promise<{ url }>` | - |
| renderImage | Render the decorator for an image node | `(node) => unknown` | - |
| theme | Image CSS theme configuration | `{ image?: string; blockImage?: string }` | - |

## Usage Examples

### Basic Image Setup

```typescript
editor.registerPlugin(ImagePlugin, {
  defaultBlockImage: true,
  handleUpload: async (file) => ({ url: await upload(file) }),
  theme: {
    blockImage: 'custom-block-image',
    image: 'custom-image',
  },
});
```

### Programmatic Image Insertion

```typescript
editor.setDocument('markdown', '![Landscape](/uploads/photo.jpg "Beautiful landscape photo")');
```

### Drag & Drop Implementation

```typescript
const handleImageDrop = (files: FileList) => {
  Array.from(files).forEach((file) => {
    if (file.type.startsWith('image/')) {
      editor.dispatchCommand(INSERT_IMAGE_COMMAND, { file, maxWidth: 800 });
    }
  });
};
```

### Custom Image Component

```typescript
const CustomImageComponent = ({ node, editor }) => {
  const [isLoading, setIsLoading] = useState(true);
  const [hasError, setHasError] = useState(false);

  return (
    <div className="custom-image-wrapper">
      <img
        src={node.getSrc()}
        alt={node.getAltText()}
        onLoad={() => setIsLoading(false)}
        onError={() => setHasError(true)}
        style={{
          width: node.getWidth(),
          height: node.getHeight(),
          maxWidth: node.getMaxWidth()
        }}
      />
      {node.caption && <div className="image-caption">{node.caption}</div>}
    </div>
  );
};
```
