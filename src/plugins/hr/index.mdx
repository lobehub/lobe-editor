## Introduction

The Horizontal Rule plugin adds a `horizontalrule` node for separating content. Type `---`, `***` or `___` on an empty line and press Enter to insert one, or dispatch `INSERT_HORIZONTAL_RULE_COMMAND`. The node is exported to Markdown as `---`, read back from Markdown thematic breaks, and round-trips through LiteXML as `<hr>`.

## Basic Usage

<Demo editable={false} of={DemoIndex} />

```tsx
import { ReactHRPlugin } from '@lobehub/editor';
import { Editor } from '@lobehub/editor/react';

<Editor plugins={[ReactHRPlugin]} />;
```

## Commands

### INSERT_HORIZONTAL_RULE_COMMAND

Inserts a horizontal rule at the current selection. The command takes no payload.

```typescript
import { INSERT_HORIZONTAL_RULE_COMMAND } from '@lobehub/editor';

editor.dispatchCommand(INSERT_HORIZONTAL_RULE_COMMAND, undefined);
```

## APIs

### ReactHRPlugin

| Property  | Description                                                | Type     | Default |
| --------- | ---------------------------------------------------------- | -------- | ------- |
| className | Class name applied to the rendered divider and its theme | `string` | -       |

### HRPluginOptions

Options of the kernel plugin `HRPlugin` (used by `ReactHRPlugin` internally).

| Property  | Description                               | Type                                                   | Default |
| --------- | ----------------------------------------- | ------------------------------------------------------ | ------- |
| decorator | Renders the divider for a node (required) | `(node: HorizontalRuleNode, editor: LexicalEditor) => any` | -       |
| theme     | Class name registered as the `hr` theme   | `string`                                               | -       |
