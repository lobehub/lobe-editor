## Introduction

Table plugin enables full-featured table editing in the editor. Built on Lexical's table functionality, it provides enhanced table operations, internationalization support, custom styling, and specialized commands for table creation and manipulation. The plugin includes utilities for table management and React components for seamless table integration.

## Horizontal Scrolling

When a table is wider than the editor's text column, the scroll wrapper bleeds into the editor's own anchor padding on both sides while the table itself stays anchored to the text column at scroll position zero. As the user scrolls horizontally, the leftmost columns slide into the left gutter and the rightmost columns reveal into the right gutter — the visible clip region uses both gutters. The bleed tracks `--lobe-block-anchor-padding`; consumers that override anchor padding (for example, set it to `0`) get the matching bleed amount automatically.

## Core Architecture

### Table Node System

The plugin extends Lexical's table functionality:

- **TableNode**: Enhanced table node with custom DOM creation
- **Node Patching**: Custom table node modifications for improved functionality
- **Cell Management**: Advanced cell manipulation and navigation
- **Table Structure**: Support for complex table layouts and styling

### Column Alignment

Each column can be aligned `left`, `center`, `right` or left unset (`null`). The alignment is stored on the table node as Lexical node state (`$.colAligns` in JSON), so documents saved before this feature keep loading unchanged. Columns are aligned from the column menu (**Align left / center / right**; picking the active alignment again clears it), and the alignment follows the column when it is inserted, deleted or moved.

| Format   | Representation                                                        |
| -------- | --------------------------------------------------------------------- |
| Markdown | GFM delimiter row: `:--` left, `:-:` center, `--:` right, `---` unset |
| LiteXML  | `<table colWidths="…" colAligns="left,center,,right">`                |
| JSON     | `"$": { "colAligns": ["left", "center", null, "right"] }`             |
| Renderer | `text-align` on the cells of the column in `LexicalRenderer`          |

A cell's own text alignment still wins over the column alignment.

```typescript
import { SET_TABLE_COLUMN_ALIGN_COMMAND } from '@lobehub/editor';

editor.dispatchCommand(SET_TABLE_COLUMN_ALIGN_COMMAND, {
  align: 'center',
  columnIndexes: [1],
  table: tableNode.getKey(),
});
```

`$getTableColumnAligns(table)` / `$setTableColumnAligns(table, aligns)` read and write the alignment inside `editor.update()` / `editor.read()`.

### Command System

- **INSERT_TABLE_COMMAND**: Create new tables with specified dimensions
- **SELECT_TABLE_COMMAND**: Select entire tables or specific regions
- **SET_TABLE_COLUMN_ALIGN_COMMAND**: Set (or, with `toggle: true`, toggle) the alignment of columns
- **Table Utilities**: Helper functions for table operations and validation

### Internationalization

- **i18n Support**: Built-in internationalization for table-related text
- **Localized Labels**: Translatable table commands and interface elements
- **Multiple Languages**: Support for various locales and languages

### Utility Functions

- **Table Operations**: Helper functions for table manipulation
- **Validation**: Table structure validation and error handling
- **Navigation**: Advanced table navigation and selection utilities

## Editing Controls

In an editable editor, controls appear only around the cell under the pointer and never change the table's own borders:

- **Row grip** on the table's left edge and **column grip** on its top edge. Click a grip to select the row or column and open its menu; Shift+click extends the selection; drag a grip to move the row or column.
- **Corner grip** at the top-left selects the whole table and opens the table menu (distribute widths, delete table).
- **Insert dots**: move the pointer onto the left edge between two rows, or the top edge between two columns (including before the first and after the last), and a `+` dot with a preview line appears; click it to insert there.
- **Column resize**: drag a column boundary; hovering it shows a thin guide.

The column menu groups **Insert column left / right**, **Align** (three icon buttons, the active one highlighted), **Column width** (auto fit, distribute evenly, sync to all columns) and **Delete**. The row menu has **Insert row above / below** and **Delete**. Read-only editors and `LexicalRenderer` show none of these controls.

### Extending the menus

Register items on `ITableControllerMenuService` to add entries to the row, column or table menu. Each item has a `key`, an optional `order` and an optional `when(context)`; `context` is `{ axis: 'column' | 'row' | 'table', editor, node, selectedIndexes }`.

| Item `type` | Fields | Renders |
| --- | --- | --- |
| `'item'` (default) | `label`, `onClick`, `danger?`, `icon?` | a menu row |
| `'label'` | `label` | a small group heading |
| `'segmented'` | `options: { key, label, icon?, active?, onClick }[]` | a row of icon buttons |
| `'separator'` | - | a divider |

```tsx
const menuService = editor.requireService(ITableControllerMenuService);
menuService.registerItem({
  key: 'my-copy-column',
  label: 'Copy column',
  onClick: ({ node, selectedIndexes }) => copyColumns(node, selectedIndexes),
  order: 45,
  when: ({ axis }) => axis === 'column',
});
```

## Commands

### INSERT_TABLE_COMMAND

Create a new table in the editor:

```typescript
editor.dispatchCommand(INSERT_TABLE_COMMAND, {
  columns: '3',
  rows: '4',
});
```

**Parameters:**

- `rows`: Number of table rows, as a string
- `columns`: Number of table columns, as a string
- `includeHeaders` (optional): Lexical `InsertTableCommandPayloadHeaders` (`boolean` or `{ columns, rows }`)

### SELECT_TABLE_COMMAND

Select a table or table region:

```typescript
// Select the whole table
editor.dispatchCommand(SELECT_TABLE_COMMAND, { table: tableNode.getKey() });

// Select row 2 (pass columnIndex to select a column; extend to grow the selection)
editor.dispatchCommand(SELECT_TABLE_COMMAND, { rowIndex: 2, table: tableNode.getKey() });
```

### TablePluginOptions

| Property | Description | Type | Default |

## Utility Functions

### Table Operations

```typescript
// Check if node is a table
isTableNode(node: LexicalNode): boolean

// Get table dimensions
getTableDimensions(tableNode: TableNode): { rows: number, cols: number }

// Insert row/column
insertTableRow(tableNode: TableNode, index: number): void
insertTableColumn(tableNode: TableNode, index: number): void

// Delete row/column
deleteTableRow(tableNode: TableNode, index: number): void
deleteTableColumn(tableNode: TableNode, index: number): void
```

### Table Navigation

```typescript
// Navigate to cell
navigateToTableCell(
  tableNode: TableNode,
  rowIndex: number,
  colIndex: number
): void

// Get current cell position
getCurrentTableCell(): { row: number, col: number } | null

// Select table range
selectTableRange(
  tableNode: TableNode,
  startRow: number,
  startCol: number,
  endRow: number,
  endCol: number
): void
```

## Usage Examples

### Programmatic Table Operations

```typescript
// Create a 3x4 table with a header row
editor.dispatchCommand(INSERT_TABLE_COMMAND, {
  columns: '4',
  includeHeaders: true,
  rows: '3',
});

// Insert a row after row 1 of a table (`table` is the table node key)
editor.dispatchCommand(INSERT_TABLE_ROW_COMMAND, {
  insertAfter: true,
  rowIndex: 1,
  table: tableNode.getKey(),
});
```
