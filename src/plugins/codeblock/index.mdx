## Introduction

Codeblock plugin enhances the editor with code editing capabilities. It highlights code synchronously with `@pierre/highlights` (a WebAssembly highlighter with every language built in), supports light and dark themes and language detection, and includes markdown shortcuts and a command for language switching.

## Core Architecture

### Highlighting

The plugin uses `@pierre/highlights` for syntax highlighting:

- **Language Support**: every language in `codeLanguages` is built in, so highlighting never waits for a grammar download; other languages render as plain text
- **Theme System**: `lobe-theme` by default, any bundled theme id (`github-dark`, `one-dark-pro`, ...) loaded on demand, or a light/dark pair
- **Tokenization**: synchronous, re-run as the code changes
- **Content Security Policy**: highlighting compiles WebAssembly, so a page with a `script-src` policy needs `'wasm-unsafe-eval'`

### Node System

- **CodeNode**: Lexical's CodeNode for code block structure
- **CodeHighlightNode**: Individual syntax highlight tokens
- **Language Detection**: Automatic language detection from input patterns

### Command System

- **UPDATE_CODEBLOCK_LANG**: Change code block language
- **Markdown Shortcuts**: \`\`\`language shortcuts for quick insertion

### Markdown Integration

- **Shortcut Support**: \`\`\`language pattern recognition
- **Export/Import**: Markdown serialization with language preservation
- **Tab Handling**: Proper indentation and tab character support

## Components

### ReactCodeblockPlugin

React component wrapper for code block functionality.

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| codeTheme | Highlighting theme id, or one per color scheme | `string \| { dark: string; light: string }` | `'lobe-theme'` |
| theme | Class names for code blocks | `{ code?: string }` | - |

## Commands

### UPDATE_CODEBLOCK_LANG

Change the language of the current code block:

```typescript
editor.dispatchCommand(UPDATE_CODEBLOCK_LANG, {
  lang: 'typescript',
});
```

## Supported Languages

The plugin highlights every language in the exported `codeLanguages` list (id, name and aliases):

- JavaScript/TypeScript
- Python, Java, C++, C#
- HTML, CSS, SCSS
- Markdown, JSON, YAML
- Shell/Bash scripts
- And many more...

## Usage Examples

### Basic Setup

```typescript
const codeblockPlugin = new CodeblockPlugin(kernel, {
  codeTheme: 'github-dark',
  theme: { code: 'custom-code-style' },
});
```

### Custom Theme Configuration

```typescript
const codeblockPlugin = new CodeblockPlugin(kernel, {
  codeTheme: {
    light: 'github-light',
    dark: 'github-dark',
  },
});
```

### Language Detection

````typescript
// Markdown shortcut automatically detects language
// User types: ```typescript
// Creates code block with TypeScript highlighting
````

### Dynamic Language Switching

```typescript
// Change language of current code block
const changeLanguage = (newLang: string) => {
  editor.dispatchCommand(UPDATE_CODEBLOCK_LANG, { lang: newLang });
};
```
