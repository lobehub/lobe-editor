## Introduction

`LexicalRenderer` is a lightweight, headless component that renders Lexical editor state (JSON) as static React elements. It uses `@lexical/headless` to parse the state and a custom renderer registry to produce server-safe HTML — no full editor, plugins, or DOM binding required.

## Image Layout Stability

Block images reserve their box before they load, including in server-rendered HTML, so the text below does not move when the image arrives or fails. The ratio comes from the first of:

1. `naturalWidth` / `naturalHeight`, written by an editable `Editor` the first time an image loads
2. a legacy `width` + `height` pair
3. the approximate ratio of `thumbhash`

An image with none of these cannot reserve its height. A failed image keeps its box and shows a broken-image placeholder.

## Features

- Pure JSON → React conversion with `useMemo` caching
- SSR/SSG compatible (no browser APIs required)
- Built-in renderers for all core node types: paragraph, heading, quote, list, link, table, image, math, code block (including Mermaid), mention, file, horizontal rule
- Override system for custom node rendering
- URL sanitization for links
- Automatic heading slug generation: unique `id`s (`intro`, `intro-1`, ...) matching the editor's heading anchors
- Table column alignment (`$.colAligns`) applied as `text-align` on cells; table cells receive `colAlign` in `overrides`
